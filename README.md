# 梅田ダンジョン 3Dナビ

**コンセプト: 地下にいる人が地下の中だけを移動するためのナビ。** 梅田の地下は地上出口が至る所にあり、
地上に出れば Google Maps で足りる。だから地上出口・地上専用通路は表示も案内もしない。
出口の位置データは内部に保持し、地図の位置合わせと現地調査の基準点にだけ使う。

日本一複雑と噂の梅田地下街(B1/B2)を3Dマップで攻略するナビゲーションアプリ。
出発地と目的地の店舗を選ぶと、エレベーター・エスカレーター・階段を考慮した
ルートを3Dマップ上に描き、店舗をランドマークにした道順を日本語で案内する。

## 使い方

```bash
npx -y http-server . -p 8931 -c-1
# → http://localhost:8931 を開く(スマホは同一Wi-Fiで http://<MacのIP>:8931)
```

## 開発

- `main.js` — アプリ本体(Three.jsシーン・経路探索・UI)。編集後は要ビルド:
  ```bash
  npx esbuild main.js --bundle --outfile=app.js --format=iife
  ```
- `shops.js` — 店舗・エリアデータ(公式フロアマップから採録)
- `index.html` — UIとスタイル(スマホは640px以下でボトムシート表示)
- `app.js` — ビルド成果物(直接編集しない)

## 現地調査モード

`https://teacoffewater.github.io/umeda-dungeon/?survey=1` をスマホで開く(地上かホテルで一度開いてから地下へ)。
種別(階段 / EV / ESC / 壁・行き止まり / 通路あり / 坂 / 出口番号 / 店 / 目印 / 吹き抜け / トイレ / メモ)を選んで床をタップ → 保存。吹き抜け(地下だが地上が見える空間)は範囲の対角2点をタップ。地図では地上まで抜ける半透明の柱で表示し、案内文の目印にも使う(通路にはしない)。坂は始まり→終わりの順に2点タップし、2点目に向かって上り/下りと、ゆるい/ふつう/急を選ぶ(高低差がわかればメモに)。
目印(看板・柱・オブジェ)は場所をタップして保存し、写真はMacへ別送(撮影時刻と記録時刻で突き合わせる。メモに「写真1」等でも可)。
記録はスマホ内(localStorage)に残り、「書き出し」でJSONを共有/コピーできる。座標はメートル(`frame: metric-v1`)。
詳細地図の中に記録するときは、バーの「詳細地図」で施設を選んで「開く」。開いている間のタップはその施設のガイド座標で記録され、記録に `frame: guide:<施設ID>` が付く(広域に戻すときは「広域(実座標)」を選んで「開く」)。用途は施設の中の階段・出入口の位置合わせ。
GPS: 地上(空が見える所)で「GPSテスト」か記録フォームの「GPSを付ける」。初回の許可ダイアログでは「Appの使用中は許可」を選ぶ。
「User denied Geolocation」(拒否)になったら、Safariのアドレスバー左「ぁあ」→ Webサイトの設定 → 位置情報 →「許可」、
または 設定 → Safari → 位置情報 →「確認」に戻す。Safari以外のアプリ内ブラウザ(LINE・メール等)では取れない。

## ランドマークと写真

- `landmarks.js` の `LANDMARKS` に目印(名前・階・位置・写真)を追記すると、マップに金色のピンで表示され、案内文の曲がり角でも「「○○」の所で左へ」と使われる。ピンをタップで写真とメモ。
- `PHOTOS` はノードID(店・スポット・駅、上下接続は `v:名前`)→写真。案内文の該当行にサムネイルが付き、タップで拡大。
- 写真の取り込み: 元写真を `rebuild/photos/` に置き `python3 tools/add_photos.py rebuild/photos 記録.json` → `photos/` に縮小版が出て、撮影時刻に近い調査記録の候補が表示される。

## データの出典

- 通路網の概略座標: 梅田地下街案内図のトレース
- 店舗: 阪急三番街・ホワイティうめだ・ディアモール大阪の公式フロアマップ
- 位置関係はデフォルメした概略図であり、実際の縮尺とは異なる
